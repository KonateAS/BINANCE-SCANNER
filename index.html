Prêt en quelques étapes

Lancez le scanner en local

01

Installez les prérequis

Windows 10/11, Python 3.11+, Node.js 20+ et PostgreSQL 16+ ou Docker Desktop.

02

Préparez Python

Depuis le dossier du projet, créez l’environnement puis installez les dépendances backend.

03

Démarrez l’application

Lancez START.cmd, puis ouvrez l’adresse locale affichée dans votre navigateur.

WINDOWS 10/11PYTHON 3.11+NODE.JS 20+POSTGRESQL 16+
POWERSHELL · DOSSIER DU PROJETINSTALLATION
# Environnement et dépendances Python
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r backend\requirements.txt

# Lancez ensuite le scanner
.\START.cmd
Configuration : au premier démarrage, le script crée backend/.env depuis le modèle. Ce fichier reste local et privé. Consultez le README pour les options PostgreSQL et les détails d’installation.
